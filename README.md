# 💰 Finance Management System

A web-based platform to manage customer collections, loan tracking, and performance analysis for small-scale finance businesses.

---

## 📌 Features

### 👤 Owner
- View profits and losses
- Manage collectors
- Grant loans to collectors
- Monitor performance of collectors and customers

### 🧑‍💼 Collector
- Collect payments from customers
- Update collection status in real time
- Monitor customer payment behavior

### 🙋 Customer
- View personal payment history

### 🛠️ Admin
- Manage all users and their roles
- Secure authentication and access control

---

## ⚙️ Tech Stack

- **Frontend:** HTML, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (also using MySQL Workbench for design & visualization)
- **Tools:** Postman, Git, VS Code

---

## 🚧 Project Status

✅ Basic UI setup using HTML/CSS  
✅ Backend API with Node.js & Express  
✅ Role-based access (Owner, Collector, Customer, Admin)  
🚧 Collector Dashboard integration (in progress)  
🚧 Final testing and deployment (coming soon)
